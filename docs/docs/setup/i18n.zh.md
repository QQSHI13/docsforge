# 多语言站点

DocsForge 内置静态国际化（i18n）。在默认语言文件旁边添加翻译文件，DocsForge 会构建与语言无关的页面：每个 URL 保持相同地址，而 Service Worker 会从缓存中返回对应的语言兄弟文件（`index.<locale>.html`）。

## 启用 i18n

必须且只能有一种语言被标记为 `default`。两种等价配置方式：

**零配置** —— i18n 插件自动加载；在 `extra.i18n_languages` 下声明语言（本文档站点即使用这种方式）：

``` yaml
extra:
  i18n_languages:
    - locale: en
      name: English
      default: true
    - locale: zh
      name: 中文
```

**显式插件** —— 需要调整插件选项时，声明带 `languages:` 的插件：

``` yaml
plugins:
  - material/i18n:
      languages:
        - locale: en
          name: English
          default: true
        - locale: zh
          name: 中文
```

## 文件命名

翻译页面使用语言后缀。它们与默认页面作为兄弟文件输出，并共享相同的公开 URL。

``` { .sh .no-copy }
docs/
├── index.md          # 英文（默认） → site/index.html
├── index.zh.md       # 中文         → site/index.zh.html
├── second.md         # 英文         → site/second/index.html
└── second.zh.md      # 中文         → site/second/index.zh.html
```

`index.html` 和 `index.zh.html` 都通过相同的与语言无关的 URL 提供（`/` 和 `/second/`）。Service Worker 将用户的偏好语言存储在 IndexedDB 中，并从缓存返回对应的兄弟文件。

翻译文件可以放在 `docs/` 的任何位置，包括子目录：

``` { .sh .no-copy }
docs/
└── guide/
    ├── intro.md
    └── intro.zh.md
```

## 回退页面

`fallback_to_default` 是旧版选项，在当前与语言无关的架构中已被忽略。DocsForge 只构建实际存在的翻译，不会生成回退副本。

## 导航翻译

使用 `nav_translations` 翻译语言切换器和侧边栏中的章节与页面标题：

``` yaml
plugins:
  - material/i18n:
      languages:
        - locale: en
          name: English
          default: true
        - locale: zh
          name: 中文
          nav_translations:
            Home: 首页
            "Getting started": 入门
            Installation: 安装
```

## 语言切换器

配置 i18n 插件后，页眉会自动显示语言切换器。选择语言会将偏好写入 IndexedDB 并重新加载同一 URL；Service Worker 随后会提供对应的语言兄弟文件。页面还会生成 `<link rel="alternate" hreflang="...">` 标签以优化 SEO。

## 每种语言的站点名称和描述

为特定语言覆盖 `site_name` 和 `site_description`：

``` yaml
plugins:
  - material/i18n:
      languages:
        - locale: en
          name: English
          default: true
          site_name: My Project
        - locale: zh
          name: 中文
          site_name: 我的项目
          site_description: 中文文档
```

## 搜索和站点地图

每种语言都有自己的搜索索引，但 URL 保持与语言无关，并且只在站点根目录生成一份站点地图。

``` { .sh .no-copy }
site/
├── search/
│   ├── search_index.json     # 默认语言
│   └── search_index.zh.json  # 中文
└── sitemap.xml
```

前端会根据当前显示的语言加载 `search/search_index.<locale>.json`，因此搜索结果会保持在同一种语言中。

将唯一的根站点地图提交给搜索引擎。站点地图指向与语言无关的规范 URL。

## 工作原理

1. 构建时为每个翻译页面输出 `index.html` 和 `index.<locale>.html` 作为兄弟文件。
2. 缓存清单会列出这两个文件。
3. Service Worker 在激活期间缓存所有兄弟文件。
4. 每次页面请求时，Service Worker 从 IndexedDB 读取偏好语言，如果已缓存则返回对应的兄弟文件，否则返回默认的 `index.html`。
5. 语言切换器将新偏好写入 IndexedDB 并重新加载同一 URL。

## 限制

- 仅支持 `suffix` 文件布局（`index.zh.md`）。
- 语言切换器需要 JavaScript 和 Service Worker 支持；在不支持的环境下会显示默认语言。
