## Architecture

DocsForge is a **repackaging** project, not a fork:

- **Engine**: [ProperDocs](https://github.com/properdocs/properdocs) (MkDocs fork by @oprypin)
- **Theme**: [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) (by squidfunk)
- **Glue**: Unified CLI + auto-plugin registration

## Why Not Just Use ProperDocs + Material?

You can! But DocsForge gives you:

1. **One install**: `pip install docsforge` instead of 2+ packages
2. **Zero config**: No `plugins:` list to maintain
3. **Unified branding**: One CLI, one config format
