# Welcome to DocsForge

> **One package. One command. Beautiful docs.**

DocsForge is a unified documentation site generator that combines the [ProperDocs](https://github.com/properdocs/properdocs) engine with the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

## Why DocsForge?

| Problem | Solution |
|---------|----------|
| MkDocs is unmaintained | Uses actively maintained ProperDocs fork |
| Material plugins need manual config | **Auto-registered** — no `plugins:` list |
| Multiple packages to install | **Single `pip install`** |

## Quick Start

```bash
pip install docsforge
docsforge new my-docs
cd my-docs
docsforge serve
```

That's it! Material theme + search + tags are pre-configured.
